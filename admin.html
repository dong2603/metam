관리자 로그인

관리자 입력 페이지는 비밀번호가 맞을 때만 접속할 수 있습니다.

현재 버전은 순수 HTML + JS 방식이라 비밀번호 보호는 간단한 프론트엔드 잠금 수준입니다.

관리자 입력 페이지

직원 정보와 연차 사용 내역을 직접 입력하거나 엑셀 파일로 가져올 수 있습니다.

조회 페이지

엑셀 가져오기

.xlsx / .xls / .csv 파일을 읽을 수 있습니다. 가장 권장하는 형식은 employees 시트와 histories 시트가 있는 엑셀 파일입니다. 일반 연차는 1일, 반일 연차는 0.5일 차감되며 생일 연차와 공가 연차는 차감되지 않습니다.

시트/열 예시는 아래 템플릿 기준입니다.

Sheet: employees columns: name, rrnFront, department, hireDate, annualLeaveTotal Sheet: histories columns: name, rrnFront, leaveDate, leaveType, reason leaveType allowed values: 일반 연차 / 반일 연차 / 생일 연차 / 공가 연차

템플릿 파일: leave-import-template.xlsx 다운로드

내보내기 시 현재 저장된 직원 데이터는 employees 시트로, 연차 사용 내역은 histories 시트로 저장됩니다.

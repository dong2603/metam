현재 상태: 미설정

Supabase 초기 설정 안내 (SQL)

Supabase 프로젝트 생성 후 SQL Editor에서 아래 코드를 실행하여 테이블을 생성하세요.

-- 1. 직원 테이블 생성 create table if not exists public.employees ( id uuid primary key default gen_random_uuid(), name text not null, employee_no text not null unique, department text, hire_date date, annual_leave_total numeric default 15, created_at timestamptz default now() ); -- 2. 연차 내역 테이블 생성 create table if not exists public.leave_histories ( id uuid primary key default gen_random_uuid(), employee_id uuid references public.employees(id) on delete cascade, leave_date date not null, leave_type text not null, days_used numeric default 0, reason text, created_at timestamptz default now() ); -- 3. RLS 활성화 alter table public.employees enable row level security; alter table public.leave_histories enable row level security; -- 4. 모든 사용자는 조회 가능 create policy "employees_select_all" on public.employees for select to anon, authenticated using (true); create policy "leave_histories_select_all" on public.leave_histories for select to anon, authenticated using (true); -- 5. 실제 운영 권장 -- 관리자 입력/수정/삭제는 anon 공개 정책으로 열지 말고 -- authenticated 사용자 + 별도 관리자 판별 방식으로 제한하세요. -- 예: auth.users와 연결된 profiles 테이블에 is_admin 컬럼을 두고 -- using / with check 조건으로 is_admin = true 인 경우만 허용 -- 6. 테스트용으로만 관리자 쓰기를 빠르게 열고 싶다면 -- 아래처럼 insert / update / delete 정책을 추가할 수 있으나 -- 보안상 권장하지 않습니다. -- create policy "employees_insert_admin_only" on public.employees for insert to authenticated with check (true); -- create policy "employees_update_admin_only" on public.employees for update to authenticated using (true) with check (true); -- create policy "employees_delete_admin_only" on public.employees for delete to authenticated using (true); -- create policy "leave_histories_insert_admin_only" on public.leave_histories for insert to authenticated with check (true); -- create policy "leave_histories_update_admin_only" on public.leave_histories for update to authenticated using (true) with check (true); -- create policy "leave_histories_delete_admin_only" on public.leave_histories for delete to authenticated using (true);

권장 방식은 조회는 anon 허용, 입력/수정/삭제는 authenticated 관리자만 허용입니다. 현재 HTML의 관리자 비밀번호 801300은 화면 잠금용이므로, 실제 권한 통제는 반드시 Supabase 정책으로 처리하세요.

빠른 사용 순서

  1. 1) Supabase SQL 실행: Supabase에서 위 SQL로 테이블을 생성합니다.
  2. 2) 연결 설정: 위 폼에 Supabase URL / anon key를 입력하고 저장합니다.
  3. 3) 관리자 로그인: 관리자 탭에서 비밀번호 801300을 입력합니다.
  4. 4) 데이터 등록: 직원을 등록하거나 엑셀 파일로 일괄 업로드합니다.
  5. 5) 조회 사용: 이제 직원들은 조회 탭에서 자유롭게 자신의 연차를 확인할 수 있습니다.

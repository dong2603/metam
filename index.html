현재 상태: 미설정

Supabase 초기 설정 안내 (SQL)

Supabase 프로젝트의 SQL Editor에서 아래 코드를 실행하여 테이블을 생성하세요.

-- 1. 직원 테이블 생성 CREATE TABLE public.employees ( id uuid primary key default gen_random_uuid(), name text not null, employee_no text not null, department text, hire_date date, annual_leave_total numeric default 15, created_at timestamptz default now(), unique(employee_no) ); -- 2. 연차 내역 테이블 생성 CREATE TABLE public.leave_histories ( id uuid primary key default gen_random_uuid(), employee_id uuid references public.employees(id) on delete cascade, leave_date date not null, leave_type text not null, days_used numeric default 0, reason text, created_at timestamptz default now() ); -- (선택) 외부에서 접근 가능하도록 RLS 정책 설정 임시 허용 (테스트용) -- 실제 운영 시에는 적절한 RLS 정책을 추가해야 합니다. ALTER TABLE public.employees DISABLE ROW LEVEL SECURITY; ALTER TABLE public.leave_histories DISABLE ROW LEVEL SECURITY;

빠른 사용 순서

  1. Supabase 설정 탭으로 이동하여 SQL 코드를 실행하고, 발급받은 URL/Key를 입력 후 저장합니다.
  2. 관리자 페이지 탭으로 이동하여 비밀번호(801300)를 입력합니다.
  3. 직원 정보와 연차 내역을 직접 등록하거나, 엑셀 가져오기를 통해 일괄 등록합니다.
  4. 직원 연차 조회 탭에서 이름과 사번을 입력하여 정상적으로 내역이 뜨는지 확인합니다.
